API 密钥设置

密钥只保存在你本机浏览器的 localStorage 里，不会写进源码、不会上传、不会被推上 GitHub。 换电脑或清缓存后需要重新填一次。

去 platform.deepseek.com → API keys 创建，形如 sk-xxxxxxxx。只用于「AI 智能词库」和「AI 写邮件」。

⚡ 高级：直发接口（可选，实现自动连发）

浏览器不能连 SMTP，但可以 POST 到你自己的一个地址。填了它，「发信控制」里就会多出「立即直发」和自动连发能力。
你的接口会收到 JSON：{to, subject, body, from, fromName, company, contact}， 返回 2xx 即视为成功。可以用 Cloudflare Worker、Vercel Function、Make/Zapier Webhook 转发到你的 SMTP。

欢迎来到「给妙妙赚NeiNei」网页版

爸爸，这是一个纯网页版的奶粉钱作战台 —— 没有后端、没有数据库，打开就能用。

1
配置发件邮箱
左侧「⚙️ 发件身份」，只填邮箱和显示名，用于统计和签名。
2
传上今天的名单
支持 .xlsx / .xls / .csv，表头需要「公司名称 / 联系人名称 / 联系人邮箱」。
3
逐封发出去
妙妙会把每封信准备好，你点「打开邮箱客户端」发送，回来点一下「已发送」即可。进度、战绩、奶瓶都会自动记账。
4
（可选）配 API Key
想要 AI 帮你写开发信，再填自己的 DeepSeek Key，只存本地。
换设备 / 清浏览器缓存会丢数据，重要名单请用左侧「💾 数据与隐私 → 备份全部数据」导出。
